# PHP: Задание — HTML-страницы и HTTP-заголовки

Учебный проект для отработки работы с HTTP-заголовками, сессиями, редиректами и отдачей файлов в PHP.

## Цель проекта

Отработать на практике:
- установку HTTP-кодов ответа (в т. ч. 404);
- формирование заголовков для скачивания файлов;
- работу с PHP-сессиями и хранение состояния между запросами;
- выполнение редиректа и корректное завершение скрипта.

Проект не предназначен для продакшена: это учебная демонстрация базовых механизмов, которые пригодятся при разработке API и веб-сервисов.

## Функционал

### `index.php`
Главная страница со списком ссылок на остальные страницы задания.

### `1.php`
Возвращает HTTP-код 404. Браузер отображает стандартное сообщение «Страница не найдена».

### `2.php`
При открытии инициирует скачивание текстового файла `file.txt` с содержимым, переданным через GET-параметр `text`.  
Пример ссылки: `/2.php?text=Привет, это файл для скачивания`.

### `3.php`
- Запускает сессию.
- Считает количество открытий страницы в переменной `$_SESSION['views']`.
- При каждом третьем открытии (3, 6, 9, …) выполняет редирект на `4.php`.

### `4.php`
- Запускает сессию.
- Выводит общее количество открытий страницы `3.php`.
